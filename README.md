# まとめPDF

画像を複数選んで、並べかえ・回転して、1つのPDFにまとめるオフライン対応のWebアプリ(PWA)です。

- 並べかえ：左の「⋮⋮」をドラッグ、または ↑↓ ボタン
- 回転：⟲(270°) / ⟳(90°)
- ページサイズ：画像サイズのまま（余白なし）
- 圧縮：長辺2400pxまで縮小、JPEG画質80%
- 保存先：ダウンロードフォルダ
- 外部ライブラリなし（PDFは自前で書き出し）。通信は一切しません

## スマホに入れる手順（GitHub Pages）

1. GitHubで新しいリポジトリを作る（Public）
2. このフォルダの中身（index.html / app.js / sw.js / manifest.webmanifest / icons フォルダ）をアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 1〜2分後に表示される `https://ユーザー名.github.io/リポジトリ名/` をAndroidのChromeで開く
5. Chromeのメニュー(⋮) →「ホーム画面に追加」→「インストール」

一度開けば、そのあとはオフラインでも動きます。

## 設定を変えたいとき

`app.js` の先頭にある値を変えます。

- `MAX_EDGE`：長辺の上限px（大きくすると高画質・重くなる）
- `JPEG_QUALITY`：0〜1（0.8が標準）

アプリを更新したときは `sw.js` の `CACHE` の名前（`matome-pdf-v1` → `v2`）も変えると、スマホ側に新しい版が反映されます。
